# Progineer's Website (WIP)

## 🚀 Run the Project

### 🛠️ Install Dependencies & Build

```bash
npm install
```
This command installs all project dependencies.


## 📦 Frontend / Backend : 

```
npm run dev 
``` 

it launch the project server and give you access to it in local

## 🌱 Environment Variables

Check the `.env.example` file and create a `.env` file with your own values.

If you'd like to run your own test database with Prisma, feel free to text me. I can help you set it up.  

🐳I'm planning to dockerize the project soon to make local setup even easier.

## 🧬 Prisma Database : 

```
npx prisma studio
```
This opens Prisma Studio — a visual interface to view and manage your database.

```
npx prisma migrate dev
```
This applies database migrations in development and sets up your local database.
